# 图片入库实施记录

目标：在现有离线 RAG 增加可缓存的 OCR 和视觉图片解析，保留纯文本默认行为。
设计依据：用户批准的 OCR + 视觉模型 → 文本索引方案；24GB A30；离线 Linux Python 3.12；450MB 分片。

- [x] 数据源按配置扫描独立图片，唯一 ID，继承现有 manifest 权限。
- [x] 图片 OCR 子进程超时、Ollama 视觉调用、内容与版本缓存。
- [x] HTML 原位置图片描述、根目录约束、拒绝外部下载。
- [x] PDF 按页提取/渲染、保留页码、缓存已完成页面。
- [x] 配置保持默认关闭，解析结束释放视觉模型，检索保留来源。
- [x] 真实 OCR/PDF 冒烟、16 项回归与缓存/权限测试。
- [x] 独立代码审查，修复 HTM 扫描和 Python 3.10 哈希兼容问题。

发布交付：Git 提交不包含 resumable_build.py；部署补丁、Linux 依赖和视觉模型分片在仓库外制作，
以交付目录的 SHA256SUMS、build-info.json 和验证报告为准。

重点检查：图片路径逃逸、缺图或模型失败的重试、旧配置兼容性、ACL 不随缓存污染、
PDF 中混合文字/图像、模型标识变化后的缓存失效、模型切换时显存释放。
